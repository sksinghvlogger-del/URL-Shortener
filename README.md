🌐 URL Shortener (Java CLI)

A simple URL Shortener built using Java that converts long URLs into short unique codes and allows users to retrieve the original URL using a command-line interface.

🚀 Features

🔗 Convert long URLs into short codes

🔍 Retrieve original URLs using short code

📋 View all stored URL mappings

⚡ Fast and lightweight (uses HashMap)

🖥️ Menu-driven CLI interface


🛠️ Tech Stack

Java

OOP Concepts

HashMap (In-memory storage)
